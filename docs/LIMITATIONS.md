# 已知限制

本版本是 `3.1.0-dev.75` Public Preview，不是 Stable。

- 云端真实收费路径尚未全面验收；费用确认与实际生成必须在 DSH 对话中完成，界面不会静默发起付费请求。
- 尚未完成第二台物理设备验收；跨设备迁移和凭据重新绑定仍需自行验证。
- 某些 ComfyUI 版本不能通过深链自动切换工作流画布，需要在 ComfyUI 中手动打开。
- ComfyUI、模型权重、第三方节点、Piper 模型、FFmpeg 均由用户自行安装；安装包不包含它们。
- Windows x64、DSH 0.2.2-rc.1、Node 24.21 是已验收基线；其他环境未做完整承诺。
- 语音类别优先展示 ComfyUI 语音工作流；若没有，则使用本机 SAPI 或已配置 Piper。
- 云端账户的实际模型列表、权限、价格和可用性由供应商决定。
- 插件界面是 DSH 的扩展；宿主登录、权限确认和部分弹窗属于 DSH 本身。
- 默认本机实例可能指向历史地址 `127.0.0.1:8188`；使用前请确认该地址确实是你的 ComfyUI，Media Studio 不会自动启动/停止它。
