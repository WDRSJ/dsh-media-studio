# ComfyUI 连接与工作流

ComfyUI 是 Media Studio 的本地执行基础设施，不隶属于图片、视频、音乐或语音中的任何一个类别。

## 添加实例

1. 启动 ComfyUI，确认服务地址（示例：`http://127.0.0.1:8188`）。
2. 打开 Media Studio → **ComfyUI 连接**。
3. 添加实例，填写服务根地址，仅在信任该地址时允许远程管理。
4. 点击“检测连接”，检查实例、节点和模型资源。
5. 一个实例可被四种媒体共享，不需要为每种媒体重复配置。

Media Studio 不会启动、停止或安装 ComfyUI，也不会自动下载模型或第三方节点。

## 工作流来源

- **ComfyUI 用户工作流**：从实例的 userdata `workflows/` 扫描、读取、导入。
- **本地 JSON**：导入 API 格式或 GUI 格式 JSON；无法可靠转换的未知节点不会被猜测执行。
- **内置模板**：随插件提供的基础工作流，需要绑定实际模型后才能执行。

导入后可以查看依赖、输出契约、常用参数和版本；完整节点 JSON 在高级详情中。

## 自动转换与绑定

- GUI 图形 JSON 会尝试转换为 API 图；不支持的节点会明确报告。
- 工作流需要选择实际 checkpoint/UNET/CLIP/VAE 等资源。
- 缺少模型、需要外部上传图片、输出契约不完整时，界面会阻止直接执行。
- prompt/negative 等参数按实际节点映射；如果两者指向同一文本节点，negative 会被忽略以保留 prompt。

## 执行与查看

- 在 **本地工作流 → 快速生成** 选择已就绪工作流并输入提示词。
- 或进入高级工作流库导入、检查参数、执行。
- 某些 ComfyUI 版本不支持 `?workflow=` 深链自动定位画布；请从 ComfyUI Workflows 浏览器手动打开。
- 任务会保存真实状态、文件哈希与验证结果。

## 模型

模型权重不包含在本项目中。模型来自你的 ComfyUI 实例；不同工作流可能共享同一模型。Media Studio 按实际加载器和工作流关联资源，不根据文件名猜测媒体能力。
